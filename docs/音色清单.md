> 方法：阿里云官方文档《Qwen-Audio-TTS音色列表》给出 `qwen-audio-3.0-tts-flash` 的系统音色，本次**逐个真调一次**验证可用性，

## 一、先纠正一个前提

这个服务上**没有** `qwen-audio-3.0-tts-flash` 的 `voice` 叫 `Serena`/`Cherry`。
`Serena`/`Cherry` 是另一套模型（`qwen3-tts-flash`，实时语音合成）的音色；`qwen-audio-3.0-tts-flash` 用的是「龙安…」系列音色。
拿错音色服务端直接报 `InvalidParameter: [cosyvoice:]Engine error [411]: TTS speak operation failed`（实测反例在日志末尾）。

另外，这个模型**只能用** `SpeechSynthesizer` 这个接口：
`/compatible-mode/v1/chat/completions` 和 `/compatible-mode/v1/audio/speech` 都调不通（前者 400 `url error`，后者 404）。

## 三、选定的音色（2026-11-12 09:40 修订）

> 用户听过实际效果后反馈：**`longanlingxi` 听着偏老**，要「元气甜美、偏少女」的音色。
> 所以默认音色改成 **`longanxiaoxin`（龙安小昕）**，原来的选择保留为备选。

### 3.1 现在的默认：`longanxiaoxin`（龙安小昕）

官方标注「亲切活泼音」，22 岁，是这批「龙安」音色里最年轻、最元气的一个。
同一句测试文本（`哈啊，终于睡醒了。杂鱼哥哥今天也起这么早啊？快说，是不是想我了。`，`volume=100`）
实测：6.14 秒、平均 -14.7 dB / 峰值 -0.4 dB、基频中位数 **314 Hz**（比灵希的 254 Hz 高约 60 Hz，听感明显更少女）。

- `longanxiaoxin` 是唯一同时满足「官方标活泼」「22 岁最年轻」的**成年女声**，音高也最高，最贴「元气甜美偏少女」。
- `longanhuan_v3.6` 更亮更跳，但官方没标特质、音高介于灵希和小昕之间，听感更接近"俏皮"而不是"少女"。

### 3.3 怎么切换

```bash
python3 scripts/set_voice.py                # 看当前音色 + 全部可选项
python3 scripts/set_voice.py longanhuan_v3.6   # 切换并自动重启机器人
```

或者直接改插件配置 `voice` 字段再重启。想退回旧音色：`python3 scripts/set_voice.py longanlingxi`。

### 3.4 历史选择（2026-11-12 上午，已被上面的修订取代）

**`longanlingxi`（龙安灵希）**，理由见 `docs/交付报告.md` §八；一句话：可爱甜美音 + 25 岁女声，最贴阿凌「撒娇嘴硬、爱说杂鱼」的雌小鬼人设；
实测音量 -12.0 dB（12 个里第二响），配合 `volume=100` 声音够亮。用户实际听后认为偏老，故改为 `longanxiaoxin`。
