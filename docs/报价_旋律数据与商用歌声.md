# 报价单：按原曲调唱原词（旋律数据 + 歌声合成）

- 日期：2026-11-16
- 结论先行：**目前没有一家能在「零注册、零付费」的前提下，由程序调用、按谱子唱中文原词**。真正做这件事的只有 ACE Studio，但它是**桌面软件**（Windows / macOS），要用它的命令行/MCP 去驱动，必须在一台常开的 Windows 或 macOS 电脑上装着它；旋律数据则仍然要自己准备。
- 本文只报价、不做接入、不点任何付费。任何实际付费前会再给你一份确认单。

---

## 一、测量工具（所有结论共用同一把尺子）

`scripts/melody_match.py`：把参考旋律和合成结果各自转成音符序列，按时间归一成 24 格，逐格比中位音高（自动找八度平移）。
判定**贴合** = ±1 半音内比例 ≥ 0.7 且 平均误差 ≤ 0.8 半音。

本次用来卡「现在唱歌这条链路」和「本机自建引擎」：

| 输入 | ±1 半音比例 | 平均误差 | 判定 | 证据 |
| --- | --- | --- | --- | --- |
| 小星星参考旋律 vs **现在线上用的 qwen-audio-3.1-tts-next** | 0.38 | 4.61 半音 | **不贴合** | `evidence/commercial_api/match_qwen_seg0.json` |
| 小星星参考旋律 vs **本机 DiffSinger ONNX** | 0.83 | 0.41 半音 | **贴合** | `evidence/leg2_local_engine/match_svs.json` |
| 同上，正弦参考做对照 | 1.00 | 0.00 半音 | 贴合（尺子自检） | `evidence/leg2_local_engine/match_ref_sine.json` |

也就是说：
1. **文字 TTS 那句「唱法提示」（text_prompt）并不跟随谱子**——这跟之前 4 组对照测出来的结论一致（`evidence/melody_match.log`）。现在的「唱」更像带拖腔的朗诵，调子不是原曲。
2. **按 MIDI 音符喂的引擎确实是贴着谱子走的**（本机 DiffSinger 过尺子）。

## 二、真正的「按谱唱」：ACE Studio

| 项 | 情况 |
| --- | --- |
| 能力 | ✅ 正是「MIDI 音符 + 歌词 → 唱出来」。官方文档明确：AI 人声轨就是「clip 里放 MIDI 音符和歌词」；支持导入 MIDI / MusicXML，整段歌词可以粘贴到旋律上 |
| 自动化 | ⚠️ 有，但是**本机程序**：`acestudio-cli` / `ace-mcp-server`（stdio MCP），能改音符、歌词、音高、导出混音/分轨。官方标注 **Experimental**（格式可能变） |
| 跑在哪 | ❌ **只有 Windows / macOS 安装包**，文档没有 Linux 版；CLI/MCP 要 ACE Studio 本体在跑。我们服务器是 Linux，**直接装不了** |
| 渲染 | 云渲染 + 本地渲染都在桌面软件里触发，**没有「提交 MIDI + 歌词 → 拿回人声」的公开云 API**（官方问答页明确说文档里没有这样的接口） |
| 价格（官网定价页，2026-11-16 抓取） | 中国区：Artist ¥148/月、Pro ¥199/月；年付折后 ¥83.17 / ¥116.58 每月（一年 ¥1996 / ¥2798）。国际站 $29 / $38.5 每月 |
| 计划权益 | Artist 每月 2500 credits、Pro 每月 5000 credits、Pro 带 3GB / 10GB 存储与音色槽。**文档没有写「渲染一分钟人声扣多少 credits」**，所以无法据此算月成本 |
| 版权 | 官方：不主张输出作品版权，**可用于商用**；但输入素材（歌词、参考音频等）的权利要自己保证 |
| 需要你提供 | ① 一台常开 Windows/macOS 电脑（装 ACE Studio 登录你的账号）；② 软件订阅；③ 账号/支付 |
| 接入改造量 | 中～大：服务器的点歌链路 → 调那台电脑上的 CLI/MCP → 把导出的分轨回传到服务器发出去。链路多一跳、多一个故障点 |
| 2～10 首/天月成本 | 订阅 ¥148～199/月（年付 ¥83～117/月）；credits 够不够未知（取决于渲染扣费，官方未公开） |

**一句话**：能力对，但代价是「再养一台 Win/Mac + 月费」，且官方没公开渲染扣费，报价单没法把 credits 算准。

## 四、曲谱 / 旋律数据从哪来

这是「按原曲调」的另一半：**得有那首歌的音符**。

| 来源 | 有没有《天黑黑》《遇见》《小星星》 | 授权 / 商用 | 结论 |
| --- | --- | --- | --- |
| 虫虫钢琴 gangqinpu.com | ✅ 覆盖率最高（钢琴谱、简谱都有） | 站点是谱子社区；**没有可查的「商用授权 API」**，商用要单独谈 | 可人工取谱，不可批量商用 |
| 弹琴吧 tan8.com | ✅ | 同上，有版权声明页 | 同上 |
| MuseScore / MusicNotes / midishow | ✅（有 MIDI/MusicXML） | 403 挡着；条款是个人学习用途为主 | 商用风险高 |
| LilyPond 公共谱库（Mutopia）/ IMSLP | 只有公版曲目（**小星星可以**） | 公版，可自由用 | 只解决儿歌/老歌 |
| 版权方直采（腾讯音乐/网易云等） | 理论上可谈 | 需商务合同，量小基本不接 | 不现实 |
| **自己扒谱** | 任意歌 | 自己产出，无授权问题 | 最现实：一次扒一首，存成 MIDI |

**结论**：孙燕姿两首歌的「原曲调」数据，正规渠道**没有现成可买的接口**；短期要么人工扒谱（一首歌一个小时以内），要么只用公版曲目。儿歌/老歌没这个问题。

## 五、本机自建引擎（第 3 项实测结果并入比较）

| 项 | 实测值 |
| --- | --- |
| 模型 | DiffSinger 移动版 ONNX（MIT）+ HiFiGAN 声码器，共 **166 MB**（磁盘） |
| 依赖 | onnxruntime（装在临时目录，147 MB） |
| 内存峰值 | **464.7 MB**（本机空闲约 1.4 GB，够跑，但余量不大） |
| 速度 | 14 个音符 → 5.42 秒音频；声学模型 0.27 s，声码器 **5.40 s**；**约 1 秒算 1 秒音频**（CPU，无 GPU） |
| 音高贴合 | **0.83 / 0.41 半音 → 贴合** |
| 致命缺陷 | 这个导出**没有音素表**，歌词没法映射成中文发音——能唱对调子，但**唱不出字**，只是「啊～」 |
| 补齐需要 | 一份带音素表的中文 DiffSinger 模型（OpenCPop 系，HuggingFace/魔搭上有单说话人中文模型，但导出 ONNX + 音素表 + 演唱时长预测要自己折腾） |
| 成本 | 软件 0 元；电费忽略；风险是调试时间（音素表/时长模型对不上会一直出怪音） |

> 如果只要求「哼出原曲调」，本机引擎**现在就能用**（调子对、词不对）。
> 如果要求「唱出原词」，本机引擎还差音素表和中文模型这一块。

## 七、我的建议（供你点头，不是已执行）

1. **调子部分**：走「本机 DiffSinger + 人工扒谱」。零月费、已过硬尺子、服务器跑得动；先只交付「哼出原曲调」，词先用真歌词做显示 + 语音里含糊带过，明确告诉她这是「哼版」。
2. **要真唱出词**：要么补中文音素模型（继续零成本，但工期不确定），要么上 ACE Studio（月费 ¥148 起 + 一台 Win/Mac 常开）。**这两条都需要你点头**，尤其是 ACE 那条要买订阅、登账号。
3. **现在线上那句「词是原词，调子是我自己编的」保持诚实**——在过尺子之前，不能对外说「按原曲调」。

**需要你先定的两件事**：
- 是接受「哼出原曲调、词只显示不唱」，还是要「真人式按谱唱中文词」？
- 如果要后者，愿不愿意为 ACE Studio 出 ¥148～199/月并准备一台常开的 Windows/macOS 电脑？
